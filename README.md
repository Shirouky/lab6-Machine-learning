# lab6-Machine-learning
Анализ тональности и кластеризация заголовков отзывов о банках. Сравнение предобработки текста (лемматизация, стоп-слова). Классификация: SGDClassifier + CountVectorizer. Кластеризация: Word2Vec + KMeans + t-SNE. Оценка влияния препроцессинга на точность и структуру кластеров.
