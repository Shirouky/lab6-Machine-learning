# Лабораторная работа №6: Анализ тональности и кластеризация заголовков отзывов

## Описание
В работе решается задача бинарной классификации тональности (положительный/отрицательный) и кластеризации заголовков отзывов о банках. Используется датасет `parsed_reviews3.csv`, содержащий тексты отзывов, рейтинги и названия банков. Проведено сравнение качества моделей при использовании предобработки текста (лемматизация, удаление стоп-слов) и без неё. Для классификации применён линейный классификатор SGDClassifier с векторизацией CountVectorizer. Для кластеризации использован подход на основе Word2Vec + KMeans, выполнена визуализация кластеров с помощью t-SNE. Оценено влияние предобработки на качество классификации и на интерпретируемость кластеров.

## Технологии
- **Python 3.7+**
- **pandas, numpy** – обработка данных
- **nltk, pymorphy3** – предобработка текста (токенизация, лемматизация, стоп-слова)
- **scikit-learn** – CountVectorizer, SGDClassifier, KMeans, TSNE, метрики
- **gensim** – обучение Word2Vec
- **matplotlib** – визуализация t-SNE
- **tqdm** – прогресс-бары

## Функциональность

### 1. Загрузка и подготовка данных
- Чтение датасета `parsed_reviews3.csv`.
- Выборка 5000 случайных записей.
- Создание бинарной метки тональности: `label = 1`, если рейтинг > 3, иначе `0`.
- Для кластеризации используются уникальные заголовки (удаление дубликатов).

### 2. Предобработка текста
Реализована функция `preprocess_text`, которая включает:
- Приведение к нижнему регистру.
- Извлечение только кириллических слов.
- Лемматизацию (с использованием `pymorphy3`).
- Удаление стоп-слов (из `nltk.corpus.stopwords`).

Предобработка может быть включена/отключена для сравнительного анализа.

### 3. Классификация тональности
Класс `SentimentClassifier`:
- Использует `CountVectorizer` для векторизации.
- Масштабирование признаков через `StandardScaler` (без центрирования).
- Модель: `SGDClassifier` с логистической функцией потерь и L2-регуляризацией.
- Оценка: `Accuracy` и `F1-macro`.
- Вывод топ-10 наиболее значимых слов для каждого класса (коэффициенты модели).

### 4. Кластеризация заголовков
Класс `TextClusterer`:
- Предобработка текста (опционально).
- Обучение модели Word2Vec на списках слов.
- Преобразование каждого текста в вектор как среднее векторов слов.
- Кластеризация методом KMeans.
- Автоматический выбор оптимального числа кластеров по силуэтному коэффициенту (поиск по k от 2 до 10).
- Визуализация кластеров с помощью t-SNE (2D проекция).
- Вывод примеров заголовков из каждого кластера.

### 5. Сравнение результатов
Для обеих задач (классификация и кластеризация) выполнено сравнение с предобработкой и без неё:
- **Тональность**: оценены accuracy и F1-macro, проанализированы топ-признаки.
- **Кластеризация**: сравнены значения силуэтного коэффициента и визуальное качество разделения кластеров на t-SNE проекциях.

## Результаты

### Классификация тональности
| Режим                 | Accuracy | F1-macro |
|-----------------------|----------|----------|
| Без предобработки     | 0.8990   | 0.8516   |
| С предобработкой      | 0.9000   | 0.8524   |

Качество классификации незначительно улучшилось после предобработки. Топ-признаки (слова с наибольшими положительными/отрицательными весами) стали более информативными после лемматизации и удаления стоп-слов.

### Кластеризация заголовков
| Режим                 | Оптимальное k | Silhouette score |
|-----------------------|---------------|------------------|
| Без предобработки     | 2             | 0.078            |
| С предобработкой      | 2             | 0.133            |

Предобработка повысила силуэтный коэффициент, кластеры стали более компактными и интерпретируемыми. На t-SNE визуализациях кластеры с предобработкой лучше разделены. Однако в обоих случаях оптимальное число кластеров равно 2, что соответствует интуитивному разделению на положительные и отрицательные отзывы (несмотря на то, что кластеризация выполнялась без использования меток).

#### Примеры кластеров (с предобработкой)
- **Кластер 0 (негативные/нейтральные отзывы)**: "Модульбанк", "Односторонний порядок", "Банк постоянно обманывает", "Не выполняют обязательства".
- **Кластер 1 (позитивные отзывы)**: "Самый лучший и удобный банк.", "Одна из самых удобных кредитных карт - точно Тинькофф!", "Благодарность банку", "Хороший банк".

- Сохранение и отображение топ-признаков для интерпретации модели классификации.

## Выводы
- Предобработка текста (лемматизация и удаление стоп-слов) незначительно улучшает качество классификации тональности, но существенно повышает интерпретируемость признаков и качество кластеризации.
- Кластеризация без предобработки даёт менее чёткие кластеры с более низким силуэтным коэффициентом. После предобработки кластеры становятся более связными и соответствуют смысловому разделению отзывов.
- Оптимальное число кластеров в обоих случаях равно 2, что указывает на естественное разделение на положительные и отрицательные отзывы.
- Подход на основе Word2Vec + KMeans показал свою пригодность для тематического моделирования коротких текстов (заголовков отзывов).
